# Validation tests

Known-answer tests, fixture comparisons, and balance/residual checks go here — not
ordinary unit tests. Each test in this directory should be traceable to a specific
acceptance-criterion bullet in `FabTwin & FabChem Overview.md` section 4.6.

Empty at P0 by design. First real content lands at Gate T2 (SPC/capability formulas
checked against NIST Engineering Statistics Handbook worked examples) and Gate T4/4.5
(SECOM/LAM9600 external validation).
